# Dispatch Announcer

Autonomous announcer for Newbold Radio. Tails the newest ExternalRadio log and speaks one line through macOS `say` the moment a new track starts. Runs forever and logs its own activity.

## Run

```
python3 dispatch_announcer.py
python3 dispatch_announcer.py --demo
python3 dispatch_announcer.py --say "test"
```
