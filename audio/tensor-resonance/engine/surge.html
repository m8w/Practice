Setup, once: in Surge XT's menu, open the OSC settings and switch OSC input on (port 53280). A web page can't send OSC by itself, so keep ./surge.sh running (or the engine, ./run.sh); either one does it. OSC never touches MIDI, so it can't collide with IAC Bus 1. To change Surge on another Mac, put that Mac's IP in SURGE ON (Surge there needs OSC input on too).

How Surge actually does it (from its source): a program change only loads a patch from Surge XT/Patches/MIDI Programs/ in Surge's user folder (yours is in ~/Music). Bank 0 = the patches loose in that folder, bank 1, 2, … = its subfolders in name order, 128 patches each at most. The folder starts empty, so program changes do nothing until it is filled; an empty slot is ignored. FILL (or python surge.py --midi-programs) copies the factory patches in, one category per bank. Restart Surge afterwards. Use the standalone Surge XT app: the VST3 build doesn't receive program changes, and inside Logic program changes may not reach it. Give this its own MIDI lane (an IAC bus named Tensor), not IAC Bus 1.
