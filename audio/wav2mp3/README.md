# wav2mp3

Converts every .wav in a chosen folder to .mp3, saved next to the original.

## Run

```
brew install ffmpeg
python3 wav2mp3.py            # folder picker
python3 wav2mp3.py /some/dir
```

## Source

Rebuilt from the chat it was made in (replaying every file write and edit in order), then syntax-checked.

Part of the [xik6 Audio Rack](https://m8w.github.io/Practice/).
