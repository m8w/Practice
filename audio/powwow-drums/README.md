# Powwow Drums

Generative percussion engine for the Supernova II, structurally inspired by Plains powwow drumming (steady pulse, honor beats, call-and-response, sneak-up crescendo). It doesn't reproduce any specific ceremonial song.

## Run

```
pip3 install mido python-rtmidi
python3 powwow_drums.py
```
