# Random SoundFont

Builds random SoundFont 2 (.sf2) files from a pile of .wav files: random key splits, velocity layers or drum kits, with random loop points, envelopes, filters, pan, tuning and LFOs. Pure standard library; ffmpeg is used for conversion.

## Run

```
python3 random_soundfont.py --help
```
