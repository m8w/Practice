# SN2 Backup

SysEx backup and restore for the Supernova II, over the same chain as sn2_gen.py (Mac mini ↔ microKORG XL ↔ Supernova II). Needs the return path: SN2 MIDI Out → Korg MIDI In.

## Run

```
python3 sn2_backup.py --help
```

## Source

Copied from the working copy on the Mac mini.
