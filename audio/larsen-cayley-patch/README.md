# LARSEN × CAYLEY patch

The LARSEN feedback instrument and the CAYLEY engine joined as a patch, in Pure Data (`larsencayley.pd`) and Max (`larsencayley.maxpat`, the latest larsencayley4 version).

## Run

```
Open larsencayley.pd in Pure Data, or larsencayley.maxpat in Max 8/9
```
