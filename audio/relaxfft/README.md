# relaxfft

An FFT "compositional relaxation" effect after Tasinato's relaxation dark-energy model: each spectral bin relaxes toward an equilibrium along a power law.

## Run

```
pip3 install numpy soundfile
python3 relaxfft.py --demo
python3 relaxfft.py --help
```
