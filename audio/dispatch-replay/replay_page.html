Recordings

Subfolders are included. Add your recording drives here, for example /Volumes/Seagate 8TB/recordings. If a drive is unplugged its recordings stay listed and are skipped until it is back.

A recording becomes playable and airable once it has stopped growing for this long, so a file OBS is still writing, or one still copying in, is never aired half-finished.

How it airs

Through OBS: this page scripts OBS. It builds a scene with a media source and plays each recording in it, while OBS keeps streaming as it always does. On its own: this program streams with ffmpeg, so OBS can carry on with the live show or stay closed.

OBS
  1. In OBS open Tools → WebSocket Server Settings.
  2. Tick Enable WebSocket server. Keep port 4455.
  3. Click Show Connect Info, copy the password and paste it below.
Direct

Keys are hidden after saving. Each URL gets its own connection; if one drops, the others keep going and it reconnects on its own.

At 11:45 each stream reconnects, so every YouTube archive stays under 12 hours. The recording keeps playing through the change.
