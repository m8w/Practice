# SN2 Tools

Overnight helpers for the Supernova II: `sn2_chaos8.py` (8 independent random note + mod-wheel channels), `sn2_segment_recorder.py` (rolling MIDI recorder that writes a new .mid every 6 hours), `reprogram_watcher.py` (fixes incoming performance dumps and sends them back) and `monitor_sn2_audio.py` (self-healing audio supervisor).

## Run

```
python3 sn2_chaos8.py
python3 monitor_sn2_audio.py
```
