# Noodle Network

A Cell abstraction for wiring oscillators and LFOs in serial, parallel, matrix or recursive topologies, with feedback cycles and OS-sourced entropy. `pd/` holds the Pure Data version (`noodle_soup_stereo.pd` and its `cell_*~` abstractions); `noodle_soup_demo.wav` is a sample render.

## Run

```
python3 noodle_network.py
Open pd/noodle_soup_stereo.pd in Pure Data
```
