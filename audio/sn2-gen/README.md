# SN2 Gen

Generative MIDI controller for the Supernova II: drift (slow CC random walks), scatter (Cage-style probabilistic notes) and more. `sn2gen1.py` and `sn2gen2.py` are earlier versions.

## Run

```
pip3 install mido python-rtmidi
python3 sn2_gen.py
```
